# Team Member Images

Place your team member images in this folder with the following names:

1. `hafiz.jpg` - Hafiz Bekele's photo
2. `ashenafi.jpg` - Ashenafi's photo
3. `mekdelawit.jpg` - Mekdelawit (Butu)'s photo
4. `binyam.jpg` - Binyam (Balemual)'s photo
5. `kalkidan.jpg` - Kalkidan's photo

## Image Requirements:

- **Format:** .jpg, .jpeg, or .png
- **Recommended Size:** 400x400 pixels (square)
- **File Size:** Keep under 500KB for faster loading
- **Quality:** High resolution, clear face photo

## How to Add Images:

1. Save your team photos with the exact names listed above
2. Copy them to this folder: `client/public/images/`
3. The images will automatically appear on the About page

## Example:
```
client/public/images/
├── hafiz.jpg
├── ashenafi.jpg
├── mekdelawit.jpg
├── binyam.jpg
└── kalkidan.jpg
```

If an image is not found, it will show a fallback with the first letter of the name.
